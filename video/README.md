# 포트폴리오 소개 영상

Unboxing 프로젝트를 60초로 소개하는 모션그래픽 영상. [Remotion](https://remotion.dev)으로
**코드에서 직접 MP4를 렌더**한다 — 화면 녹화가 아니다.

```bash
cd video
npm install
npm run studio   # 미리보기 (타임라인을 스크럽하며 수정)
npm run render   # out/unboxing.mp4 생성
```

## 왜 녹화가 아니라 렌더인가

앱이 이미 React라서 실제 컴포넌트를 그대로 영상 프레임으로 찍을 수 있다. 마우스 커서도
브라우저 UI도 없고, 해상도를 마음대로 올릴 수 있고, 타이밍이 프레임 단위로 재현된다.
문구 하나를 고쳐도 다시 녹화할 필요 없이 `npm run render`만 다시 돌리면 된다.

대신 **구동부는 다시 써야 했다.** Framer Motion은 시간 기반이라 같은 프레임이 매번
같은 그림을 내놓지 않는다(렌더가 깨진다). 그래서 `components/Box.tsx`, `Rays.tsx`는
원본의 SVG 기하를 그대로 두고 애니메이션만 "경과 프레임의 순수 함수"로 옮겼다.
좌표를 고칠 일이 생기면 원본([src/components/unboxing/](../src/components/unboxing))과
양쪽을 같이 고쳐야 한다.

## 구성

| 파일 | 역할 |
|---|---|
| `src/Root.tsx` | 컴포지션 등록 (1920×1080, 30fps, 1800프레임) |
| `src/Video.tsx` | 전체 타임라인. 장면 순서·길이·전환을 여기서만 바꾼다 |
| `src/tokens.ts` | 앱의 디자인 토큰 사본 — 색이 어긋나면 여기부터 본다 |
| `src/data.ts` | 실제 아카이브 스냅샷에서 화면에 쓸 기도제목을 고른다 |
| `src/scenes/` | 장면 8개 (S1~S8) |
| `src/components/` | 박스·광선·카드·자막 등 장면들이 공유하는 조각 |

장면 길이를 바꾸려면 `Video.tsx`의 `CHAPTERS`에서 `from`/`duration`만 고치면 된다
(뒤 장면들의 `from`도 함께 밀어야 한다). 각 장면은 자기 로컬 프레임만 알고,
장면 사이 페이드는 `CrossFade`가 전담한다.

## 화면에 나오는 데이터

기도제목·또래·반응 수는 전부 실제 운영 데이터(`src/lib/data/prayers.json`)다.
스냅샷 단계에서 이미 이름이 마스킹되어 있어 그대로 띄워도 개인정보 문제가 없다.

예외는 **검색 장면(S5)과 마스킹 장면(S7)의 인물**로, 여기만 `홍길동`이라는 데모를 쓴다.
아카이브에서 실명을 지워놓고 영상에서 실명을 타이핑해 보여주면 마스킹한 의미가
없어지기 때문이다. 이 두 곳에 실제 참가자 이름을 넣지 말 것.

## 소리

무음으로 렌더된다. BGM을 얹으려면 음원 파일을 `public/`에 넣고 `Video.tsx`에서
Remotion의 `<Audio>`를 쓰면 된다. 포트폴리오 사이트에 임베드할 때는 자동재생이
음소거로 시작하는 경우가 많아, 설명은 전부 자막으로만 전달되게 구성했다.
